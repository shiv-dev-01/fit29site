# FIT29

Marketing site for **FIT29**.

The repository name is `fit29site` because this project is the site code for FIT29.

## Stack

- React
- Vite
- React Router
- Tailwind CSS
- TypeScript

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/fit29site.git
cd fit29site
npm install
npm run dev
```

The dev server opens at http://localhost:5173.

## Scripts

| Command | What it runs |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `vite build` |
| `npm run build:dev` | `vite build --mode development` |
| `npm run lint` | `eslint .` |
| `npm run preview` | `vite preview` |
| `npm run test` | `vitest run` |
| `npm run test:watch` | `vitest` |
